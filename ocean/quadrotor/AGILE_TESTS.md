# Agile Flight Tests

This file tracks agile-flight experiments only. Use `AFL-###` IDs here. Keep
exploration/frontier work in `TESTS.md`.

Native backend note, June 23, 2026: the zero-action native eval blocker exposed
during AFL-044 was not an environment or policy issue. The remote target had
changed to an RTX 3080 (`sm_86`) while the backend had been rebuilt for
`sm_120`, so custom CUDA kernels failed even though CUBLAS matmuls still ran.
The raw checkpoint layout also required 32-byte allocator alignment to match the
Torch-compatible `.bin` layout. After rebuilding with `NVCC_ARCH=sm_86` and
using 32-byte alignment, native eval of AFL-038 on `agile_pillar_l2_open`
returns `99.62%` success, `0%` timeout, `0.38%` obstacle hits, `avg_vel=2.22`,
and `action_delta=0.113` over a short 512-episode sanity run.

Precision note, June 23, 2026: direct-motor quadrotor training must use the
float32 native backend (`build.sh quadrotor --float`, `precision_bytes=4`).
The AFL009 wrapper briefly rebuilt default bf16 (`precision_bytes=2`), causing
loaded float checkpoints to produce saturated actions and near-immediate
crashes in AFL-046/AFL-047. The wrapper now defaults to float32 for GPU runs;
set `AFL009_FLOAT_BUILD=0` only for an explicit bf16 experiment.
